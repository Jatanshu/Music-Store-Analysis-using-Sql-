# Music-Store-Analysis-using-Sql

# Overview

This project focuses on analyzing a Music Store Database using SQL. It includes multiple real-world business queries that uncover insights about customers, employees, tracks, genres, and overall sales performance.
It demonstrates strong SQL querying skills and understanding of relational database concepts.

# Features & Objectives

- Designed and explored a relational Music Store Database
- Wrote SQL queries ranging from beginner to advanced
- Performed data analysis on sales, customers, employees, and tracks
- Solved practical business problems using JOINs, GROUP BY, CTEs, Subqueries, Aggregate Functions

# Technologies Used

- PostgreSQL / MySQL (compatible SQL syntax)
- SQL Concepts Used:
  -- JOIN (INNER, LEFT, RIGHT)
  -- GROUP BY & HAVING
  -- ORDER BY
  -- Subqueries
  -- CTE (WITH clause)
  -- Aggregate Functions (SUM, MAX, COUNT, AVG)
  -- DISTINCT, LIMIT
  -- Filtering with WHERE
